# LLM Study Journey

This repository is my personal study journal for learning how large language models are built and optimized.

It contains small, practical experiments that I can read, modify, run, and benchmark while developing my understanding of LLMs. The repository is intended for learning and exploration rather than production use.

## Current Experiments

- [transformer.ipynb](transformer.ipynb): Initial transformer implementation and experiments.
- [kv_cache/](kv_cache/): KV-cache implementation, generation comparison, and benchmark.
- [kv_cache/readme.md](kv_cache/readme.md): Notes and results for the KV-cache experiment.

The repository will grow as new LLM topics and experiments are added to the study journey.
